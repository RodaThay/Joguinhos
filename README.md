# Joguinhos 🎮

Bem-vindo ao meu repositório de jogos criados com Java! Este é um espaço onde estou praticando lógica de programação e desenvolvendo pequenos projetos de jogos simples.

## Projetos Atuais

### 1. Jogo da Adivinhação
O clássico jogo onde o computador escolhe um número secreto entre 1 e 100 e você precisa adivinhar qual é.
- **Como funciona:** O programa gera um número aleatório e, a cada palpite, ele te dá uma dica dizendo se o número que você digitou é muito baixo ou muito alto.
- **Objetivo:** Acertar o número secreto no menor número de tentativas possível.
